Project status

Development evidence and open work

What exists, what is not release-bound, and what practical evaluation requires.

Status: alpha research preview. An August 2026 Finnish replay run reported 0.23% mean normalized text edit distance against its declared Finlex comparison surface. The exact run package is not public, and APIs, certificate formats, and uniform frontend conformance remain in development.

What is established

  • For declared Finnish source/profile scopes, covered recurring amendment forms can be compiled into typed, inspectable text-state transitions.
  • The alpha workflow carries point-in-time trees, operation provenance, mutation accounting, findings, and comparison residuals together.
  • Different source regimes can reuse a shared core while keeping jurisdiction-specific acquisition, drafting idioms, and source pathology local.
  • One Estonia finding has completed the loop from replay divergence to official-publisher confirmation and correction.

What is not established

  • No jurisdiction receives a blanket certification or legal-authority claim.
  • Frontend maturity is uneven; source acquisition, effect parsing, dry-run evidence, replay, PIT state, and public artifacts must be assessed independently.
  • The public Python API, CLI JSON families, certificate bundle, and long-term service interface are not yet stable compatibility promises.
  • A moving development checkout is not release evidence; exact reproduction needs the named software, sources, corpus, configuration, and output package.

Portfolio

Finland remains the reference replay frontend. Estonia, the UK, New Zealand, Norway, Sweden, EU, and US federal lanes exercise other authority and source models in mainline. Japan, South Korea, Poland, and Switzerland are active staging frontends not yet integrated into mainline.

Inspect the frontend registry and claim ceilings.

How to evaluate it

Institutions can begin with a bounded no-write pilot. Technical evaluators can use the current command paths. Contributors and maintainers can use the work-package map.

Public evidence discipline

Stable claims should name their source and software snapshots, command, corpus, comparison role, residual account, and date. Unconfirmed publisher divergences remain candidates. A score is a regression surface, not a correctness percentage.
