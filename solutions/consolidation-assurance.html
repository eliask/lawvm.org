Consolidation assurance

Can the current text be derived from what was enacted?

LawVM independently replays declared amendment sources, compares the resulting state with the published consolidation, and turns each disagreement in that scope into a source-linked review item.

Official publishers

Legal publishers

Ministries and drafting offices

Researchers and civic infrastructure

Build reproducible evidence about how legal state is derived rather than treating the latest HTML page as complete history.

Evidence path

Every result keeps its source path.

before state+amending source+effective date→candidate state↔published text
  1. Inventory authority and sources. Identify original acts, amendments, commencement evidence, consolidated versions, and missing links.
  2. Compile typed transitions. Parse the instruction, resolve its target, extract its payload, and preserve rejected or ambiguous candidates.
  3. Check the mutation boundary. Compare the paths that changed with the declared target region and any explicitly owned migration or recovery path.
  4. Compare without declaring a winner. Classify agreement, LawVM defect, source gap, manual frontier, compare-shape difference, or candidate publication issue.
  5. Return a review queue. Package source locators, dates, diffs, rules, residuals, reproduction data, and any institutional disposition.
Disposition boundary: each difference opens a source review. Legal interpretation, source authority, and editorial sign-off remain with the institution’s reviewers.

First bounded pilot

One source-complete transition corpus.

Source-readiness comes first: freeze a declared, source-complete transition corpus or return a blocked-source map with missing authorities and dates. A comparison result cannot be clean when its source universe is unknown.

Inputs

Original and amending acts, effective-date evidence, before/after consolidations, identifiers, source authority notes, and a local legal reviewer.

Outputs

Source census, replay surface, classified discrepancy ledger, evidence packets, reproducible artifacts, and a recurring-monitor recommendation.

Operating mode

No production writes; frozen source snapshot; narrow operation families; findings remain candidates until reviewed.

Success criterion

Every declared transition receives an explicit disposition or named owner; none is silently dropped or repaired.

Publication boundary: LawVM is a read-only QA layer. It returns a candidate or review result and never writes, publishes, or automatically corrects the official text.
