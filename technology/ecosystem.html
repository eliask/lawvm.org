LawVM

Standards and ecosystem

An assurance layer beside the systems that create and publish law.

LawVM sits beside drafting editors, XML standards, identifier vocabularies, publishing systems, and official portals. Through source-specific adapters, it can consume versioned artifacts, reconstruct supported transitions, and return inspectable evidence.

Three entry paths, one model

Meet the source where it is.

Source bootstrap

Paper, scans, PDFs, and incomplete archives first yield preserved manifestations, extraction witnesses, structure evidence, and an explicit blocked-source map.

Pre-publication QA

A versioned drafting or publication export can receive declared target, reference, legal-time, language, and mutation checks through a concrete adapter.

Published-text audit

A bounded set of amendment sources and published states can support independent replay, classified differences, and a review queue.

Shared decision chain

Each route moves from declared sources and a model to QA checks, then a strict or observe-only disposition and a named human decision. LawVM does not automatically publish or correct text.

Future strict-authoring direction: legislation co-produced with a formally specified machine artifact could make consolidation automatic and machine-checkable within its accepted formal domain. This requires source closure, human-text/artifact correspondence, compiler and replay proofs, independent checking, and rejection or blocking of unsupported input. See the full conditional boundary.

Integration patterns

Start where structure and authority already exist.

Akoma Ntoso input

Map stable structural units and metadata into LawVM’s source-document boundary; keep jurisdiction-specific amendment idioms in the frontend.

ELI and effect feeds

Use identifiers and effect relationships as source witnesses and candidates. Promotion into executable transitions still requires target, payload, temporal, and mutation-boundary evidence.

Drafting-system checks

Validate targets, references, effective dates, expression parity, and unintended mutation before publication. This is an integration direction, not a current universal product claim.

Publisher shadow audit

Freeze a source-complete corpus, replay it independently, classify divergence, and return evidence without writing to production.

No implied endorsement: references to standards and projects describe ecosystem roles and possible interfaces. They do not imply formal integration, partnership, certification, or endorsement unless explicitly stated.
